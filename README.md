# Ice-Cream-Store
Ice Cream Store Management System using Python and C program 
Ice Cream Store Management System

 Project Description

This is a beginner-level Ice Cream Store Management System developed using Python. It allows customers to select their favourite ice cream, enter the quantity, and calculate the total bill.

The program uses a Python dictionary to store ice cream names and their prices.

 Features

- Display ice cream menu.
- Select ice cream using menu numbers.
- Enter the required quantity.
- Calculate the bill automatically.
- Place a second order.
- Display the final total bill.
- Check invalid menu choices.

Concepts Used
  
  - Variables and Data Types
  - Dictionary
  - Input and Output
  - Conditional Statements ("if-elif-else")
  - Arithmetic Operators
